# Mac Media Player

A native macOS application for playing audio and video media stored on the user's Mac.

## Language

**Local Media**:
An audio or video file stored on the user's local filesystem and selected for playback.
_Avoid_: Stream, online media, remote media

**Playlist**:
A user-named, persistent, ordered collection of Local Media selected by the user.
_Avoid_: Media library, folder scan

**Media Library**:
An automatically scanned and indexed catalogue of media available on the user's Mac. It is not part of the MVP.
_Avoid_: Playlist
