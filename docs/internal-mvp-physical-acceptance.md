## 修复与定向复验

根因不是媒体本身或 VideoToolbox 不可用，而是锁定的 mpv `v0.41.0` 在 macOS 外部 libmpv OpenGL render API 中不能建立直接 `videotoolbox` 零拷贝设备。适配器改用仍由 VideoToolbox 执行硬件解码、再把帧复制到系统内存的 `videotoolbox-copy`，并保留 `hwdec-software-fallback=no`，因此硬件初始化失败仍会进入既有的一次性显式软件降级策略。

同时修复了关闭播放器时的生命周期竞态：关闭入口会先发布线程安全的 shutting-down 状态；100 ms 延迟硬解探测随后确认尚未开始关闭、libmpv 句柄仍存在、加载代次仍匹配且该次加载仍要求硬解，避免关闭期间调用 `mpv_get_property_string`。

## 测试稳定性修复

物理验收前的重复运行暴露了 `performsPlaybackFailureRecoveryActions` 的既有竞态：测试只等待 `.failed` 状态，尚未等待公开的 `playbackFailureNotice` 发布恢复动作就调用重试、跳过或移除。测试现改为在 Issue #17 预先约定的 `PlaybackCoordinator` 缝隙上等待对应公开恢复动作，不改变产品行为。修复后的聚焦测试重复运行 `100/100` 通过，随后正式候选构建与自动门槛全部通过。
