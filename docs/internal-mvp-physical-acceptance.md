## 现场触发的问题与处置

英文失败可稳定复现：系统设置绑定精确 App 路径并选择 English，完全退出同 Bundle ID 的全部进程，再从 Finder 打开精确归档，应用仍使用简体中文。期间分别试验了 Bundle 首选语言、当前 App Locale 和 macOS 26 `Locale.preferredLocales`，均未通过物理复验，因此这些试验已撤回，没有作为修复保留。

本轮保留的代码改动只修复资格清单生成：候选构建现在从不可变模板渲染与当前提交、二进制哈希和构建时间绑定的新清单，并由 shell 回归测试防止旧候选结果被误带入新候选。
